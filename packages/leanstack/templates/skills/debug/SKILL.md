# Debug

Load this skill alone.

1. Reproduce — name the failing check or reproduce the failure.
2. Trace — follow the bad result to the code that creates it.
3. Root cause — fix that cause. Do not patch a symptom at the edge.
4. Fix — keep the diff limited to the cause and any test that locks it.
5. Verify — re-run the same check, then stop. Do not refactor around the fix.
