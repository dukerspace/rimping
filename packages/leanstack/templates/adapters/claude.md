# claude

Prefer root or nested `AGENTS.md`. Add `CLAUDE.md` with only `@AGENTS.md` if this Claude build ignores `AGENTS.md`. Never paste the rules into both files.

Skills under `skills/*/SKILL.md` are Claude-compatible. For Normal/Hard, discover and rank skills (`core/router.md`), then load ranked bodies up to `budgets.yaml` `max_skills`. Do not install a second maintained copy of the harness under Claude-only paths.
