Use the Rimping architecture workflow. Do not run a leanstack CLI.

1. Read `AGENTS.md`, then open `core/router.md`, `skills/architect/SKILL.md`, and relevant principles.
2. Inspect the existing system before proposing changes.
3. Define: requirements, constraints, current architecture, options, tradeoffs, recommended design, migration.
4. Prefer the simplest architecture that satisfies the requirements.
5. Stop at the decision unless the user also asked to implement it.
